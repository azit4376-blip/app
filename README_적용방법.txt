GPT 보완 버전 적용 방법
========================

1) 기존 GitHub Pages /app 폴더의 파일을 백업합니다.
2) 이 폴더 안의 파일을 그대로 /app 폴더에 업로드해서 덮어씁니다.
3) 반드시 포함해야 하는 파일:
   - index.html
   - coupang.html
   - ali.html
   - app.js
   - style.css
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
   - coupang-icon.png
   - ali-icon.png
4) 업로드 후 브라우저에서 캐시를 비우거나, 주소 뒤에 ?v=2 를 붙여 확인하세요.

주요 보완점
===========

- 카카오톡 인앱 브라우저 안내를 더 명확하게 개선했습니다.
- iOS / Android / 카카오톡 환경에 따라 필요한 안내만 보이도록 분리했습니다.
- coupang.html / ali.html 단일 페이지에도 Android 안내와 외부 브라우저 열기 버튼을 추가했습니다.
- 홈 화면 아이콘에서 실행된 경우 자동으로 쇼핑 링크로 이동하는 흐름을 추가했습니다.
- 서비스워커 캐싱을 안정화했습니다. 아이콘 파일 하나가 누락되어도 설치가 실패하지 않습니다.
- 외부 쇼핑몰·어필리에이트 링크는 서비스워커가 캐시하지 않도록 정리했습니다.
- 링크 복사 버튼과 토스트 메시지를 추가했습니다.

링크 수정 위치
==============

쿠팡/알리 링크를 바꾸려면 app.js 상단의 SHOPS 값을 수정하고,
coupang.html / ali.html 의 body data-target-url 값도 같은 링크로 맞춰주세요.
