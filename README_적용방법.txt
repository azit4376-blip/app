1) 이 폴더 안의 파일을 GitHub Pages /app 폴더에 전부 덮어쓰기 하세요.
2) iPhone에 이미 만들어둔 홈 화면 아이콘은 전부 삭제하세요.
3) Safari에서 아래 주소를 직접 열어서 추가하세요.
   - 쿠팡: https://azit4376-blip.github.io/app/coupang.html?v=reset20260606a
   - 알리: https://azit4376-blip.github.io/app/ali.html?v=reset20260606a
4) 이 상태에서 공유 버튼 → 홈 화면에 추가를 누르면 이름이 쿠팡/알리로 떠야 정상입니다.
5) 새로 만든 아이콘을 실행하면 coupang.html / ali.html이 잠깐 열린 뒤 쿠팡/알리 링크로 자동 이동합니다.

중요:
- 이름이 쇼핑홈으로 뜨면 index.html에서 홈 화면 추가를 누른 것입니다.
- 반드시 coupang.html 또는 ali.html 페이지가 열린 상태에서 홈 화면 추가를 해야 합니다.
- 캐시가 남아 있을 수 있으니 테스트 주소 뒤에 ?v=reset20260606a를 붙여 확인하세요.
